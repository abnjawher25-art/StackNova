# StackNova

StackNova is an interactive learning platform for aspiring web developers. Learn HTML, CSS, JavaScript, and modern web tools through short lessons and hands-on practice.

## Getting started

Requirements: Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current learning experience

- Landing page with learning tracks
- Interactive HTML lesson with a live preview
- A small HTML heading challenge
- Browser-based progress saving
- HTML learning roadmap

## Tech stack

- Next.js 15
- React 19
- TypeScript
- CSS
