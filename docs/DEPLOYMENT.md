# نشر StackNova

## الخيار المقترح: Vercel

المشروع مبني باستخدام Next.js، لذلك يمكن نشره مباشرة على Vercel دون تحويله إلى موقع ثابت.

1. افتح https://vercel.com/ وسجّل الدخول باستخدام حساب GitHub الذي يحتوي على المستودع.
2. اختر **Add New → Project** ثم استورد المستودع `abnjawher25-art/StackNova`.
3. اترك Framework Preset على **Next.js**، ومجلد الجذر `./`، وأوامر البناء الافتراضية.
4. لا تحتاج المنصة حاليًا إلى متغيرات بيئة خاصة حتى تُبنى.
5. اضغط **Deploy** وانتظر انتهاء البناء.
6. افتح رابط النشر الذي تنشئه Vercel وجرّب الصفحة الرئيسية، مسارات HTML/CSS/JavaScript، الاختبار، المرجع، ومعرض المشاريع.
7. بعد كل دمج إلى `main)، ستنشئ Vercel نشرًا جديدًا تلقائيًا إذا بقي تكامل Git متصلًا.

## التحقق قبل النشر

يتحقق GitHub Actions من وجود ملفات المسارات الأساسية ثم ينفذ بناء الإنتاج:

```bash
npm install
npm run check:routes
npm run build
npm start
```

افتح `http://localhost:3000` بعد تشغيل أمر `npm start`.

## ما الذي يجب اختباره يدويًا بعد النشر؟

- فتح كل مسار والتأكد من عدم وجود صفحة 404 غير متوقعة.
- تجربة تحدٍ واحد على الأقل من كل مسار.
- التأكد من ظهور نتيجة الاختبار في صفحة التقدم.
- تجربة البحث والتصفية والنسخ في المرجع ومعرض المشاريع.
- فتح الموقع من هاتف ومن حاسوب.
- تذكّر أن تقدم الدروس محفوظ في `localStorage` على الجهاز والمتصفح الحالي، ولا تتم مزامنته بين الأجهزة.

## ملاحظة مهمة

هذه الخطوات تشرح النشر ولا تعني أن الموقع أصبح منشورًا بالفعل. يلزم إكمال ربط المستودع بحساب الاستضافة والتحقق من رابط النشر الفعلي.
